# Pixel Garden

Учебная галерея на PHP и MySQL без библиотек. Интерфейс использует нативные `fetch`, `FormData` и DOM API, поэтому действия выполняются без перезагрузки страницы.

## Установка на локальном сервере или PHP-хостинге

1. Создайте базу MySQL и импортируйте `schema.sql` в phpMyAdmin.
2. Скопируйте `config.php.example` как `config.php`, внесите параметры базы данных.
3. Убедитесь, что папка `uploads` доступна PHP для записи (обычно права 755 или 775 на хостинге).
4. Загрузите все файлы в корневую папку сайта. Нужен PHP 8.1+ с расширениями `pdo_mysql`, `mbstring`, `fileinfo` и `gd` или аналогичной поддержкой изображений.
5. Зарегистрируйте первый аккаунт. Для назначения администратора в phpMyAdmin выполните:

```sql
UPDATE users SET role = 'admin' WHERE username = 'ваше_имя';
```

## Роли

- Гость оставляет комментарии как «Гость» и ставит одну реакцию на публикацию в рамках браузера.
- Пользователь публикует изображения и может удалить собственный авторизованный комментарий.
- Модератор или администратор может удалить любой комментарий, в том числе анонимный.

## Ограничения

Заголовок публикации необязателен и ограничен 120 символами. Комментарий: до 300 символов, пустые сообщения отклоняются сервером. Загрузка поддерживает JPG, PNG и WebP размером до 25 МБ. Файл сохраняется как есть: приложение не меняет размер и не пережимает изображение. На хостинге нужно также выставить PHP-параметры `upload_max_filesize` и `post_max_size` не ниже `25M`.
