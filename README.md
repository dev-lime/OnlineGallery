# Online Gallery (OG)

Минималистичное веб-приложение для публикации фотографий и обсуждения кадров в формате Single Page Application.

Live Demo: [https://og.ct.ws/](https://og.ct.ws/)

---

## 📌 Особенности и функционал

* **Асинхронная работа (AJAX):** Все действия (загрузка фото, добавление комментариев, просмотр профилей) происходят без перезагрузки страницы.
* **Без сторонних библиотек:** Написан на чистом JavaScript (Vanilla JS) и PHP — никаких фреймворков, jQuery, Axios или Composer-пакетов.
* **Модальные окна:** Просмотр полноразмерных фото, комментариев и профилей авторов через native HTML5 `<dialog>`.
* **Безопасность и валидация:**
  * Клиентская и серверная защита от пустых сообщений (`trim()`).
  * Ограничение длины комментариев.
  * Экранирование спецсимволов (`htmlspecialchars`) для защиты от XSS.
  * Валидация загружаемых типов файлов на стороне PHP.
